# CANE results analysis

Interactive dashboards for the Clinical Associate National Examination (CANE), covering the MCQ and MEQ papers.

## Dashboards

- [CANE 2026](https://drjuanc.github.io/cane-analysis/cane2026/)

## What each dashboard shows

- Overall marks and pass rates, by component and by university
- Statistical comparison between universities
- Question analysis for the MEQ: facility and discrimination
- Weakest themes and topics
- Reliability: Cronbach's alpha, McDonald's omega and the standard error of measurement

## Data

All marks are anonymised. Students are identified by row code only, and universities are labelled University1, University2 and University3.

Each dashboard reads the `marks.xlsx` file in its own folder. To update a year, replace that file.
